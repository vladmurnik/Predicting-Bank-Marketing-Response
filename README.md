# Bank Marketing: Term Deposit Response Prediction

End-to-end ML project on the UCI Bank Marketing dataset: predicting whether a
client will subscribe to a term deposit after a telemarketing call.

Work in progress: dataset loader, leakage-safe features, time-based validation,
FastAPI service.

## Stack

Python 3.12 · scikit-learn · LightGBM · pandas · FastAPI · uv
